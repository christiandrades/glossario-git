
# 📘 Glossário Git/GitHub para Iniciantes

Bem-vindo ao repositório do **Glossário Git/GitHub para Iniciantes**, criado por [Christian Andrade](https://www.linkedin.com/in/christiandrades).

Este material foi elaborado para auxiliar iniciantes no entendimento e aplicação dos principais comandos e conceitos do Git e do GitHub, com uma abordagem simples, visual e objetiva.

## 📄 Sobre o Material

Este glossário foi desenvolvido em formato PDF interativo e contém:

- ✅ Explicações claras e práticas dos comandos Git
- ✅ Exemplo de uso para cada comando
- ✅ Índice para navegação rápida
- ✅ Capa personalizada e design visual com destaque em lilás
- ✅ Rodapé com contatos profissionais

## 🧠 Ideal para:

- Estudantes de tecnologia
- Devs iniciantes
- Pessoas em transição de carreira
- Quem deseja organizar seus estudos com versionamento de código
